Selected projects

Full software stack for the ECS-DoT ultra-low-power RISC-V AI SoC

2024 – present · NTU, then EMASS (an NTU/A*STAR spin-off) from 06/2025

Research and develop the device drivers, RTOS, SDK and toolchains needed to compile, optimise and run AI applications on ECS-DoT, a custom ultra-low-power SoC with a RISC-V core and dedicated hardware accelerators, designed and fabricated by the team.

Impact: Enables AI workloads on the ECS-DoT SoC; builds on the AI-accelerator driver and RTOS work done at A*STAR I²R.

MbedOS and SDK port to the ECS-DoT RISC-V SoC

2020 – 2024 · A*STAR I²R / NTU · ECS-DoT Edge SoC with AI acceleration

Ported the ARM MbedOS 5.12.4 RTOS and its SDK to the ECS-DoT SoC, covering a different CPU core, instruction set, peripherals, memory map and I/O devices. Both the original and the target platforms were poorly documented and buggy, so the work was a complex trial-and-error effort with the GCC toolchain and GDB.

Impact: Delivered a working RTOS port and board-support package; technology disclosure SWIP-PMEP-2022-31, licensed to an A*STAR spin-off.

AI accelerator Linux kernel driver port to MbedOS on RISC-V

2022 – 2023 · A*STAR I²R · ECS-DoT

Ported the AI accelerator’s ARM Linux kernel driver to MbedOS on the ECS-DoT RISC-V CPU, adapting the driver to a new operating system, memory map and device model.

Impact: Technology disclosure SWIP-PNVD-2022-33, licensed to an A*STAR spin-off.

Real-time extensions and reflective scheduling for the L4 microkernel

2004 – 2007 · NICTA · ERTOS Programme

Analysed the real-time behaviour of general-purpose L4 microkernels, identified the architectural obstacles to predictable scheduling, and designed and implemented a reflective real-time scheduler that lets a system observe and control its own temporal behaviour.

Impact: Published at IEEE RTSS 2006 and OSPERT 2006/2007 and in the EURASIP Journal on Embedded Systems; the work influenced the real-time features of the commercial OKL4 microkernel.

Linux memory-management extensions for non-volatile DIMMs

2015 · A*STAR DSI · CERN OpenLab collaboration

Extended Linux memory management to support non-volatile DIMMs, allowing persistent data to be placed directly in main memory and processed at memory speed.

Impact: Procured an invitation to collaborate with CERN OpenLab and an invited talk at CERN OpenLab 2015.

GCC backend for a custom 16-bit microcontroller

2009 – 2010 · Micron Italy (formerly STMicroelectronics) · Università di Milano-Bicocca

Ported the GNU GCC C compiler to a custom, non-standard 16-bit microcontroller managing embedded NAND/NOR phase-change memories under hard real-time constraints and security requirements. The target was poorly documented, requiring a new backend and extensive debugging with GDB.

Impact: Delivered under a Micron R&D contract; the compiler supported devices deployed in high volume.

EU ENIAC SMART and TOISE projects

2009 – 2013 · Università di Milano-Bicocca · Micron Italy and STMicroelectronics

Principal Investigator and technical lead for UNIMIB in two three-year EU ENIAC projects: SMART (techniques and tools for advanced real-time embedded firmware, €302,400) and TOISE (trusted computing for European embedded systems, €556,000). Responsible for planning, budget, recruiting research engineers and post-docs, and scientific and technical delivery.
